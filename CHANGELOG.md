# Changelog

All notable changes to the Blossom n8n node will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [3.0.7] - 2025-02-05

### Changed

- **Package metadata** – Author set to Hirez10; repository and homepage URLs updated to https://github.com/HirezRa/n8n-nodes-blossom.

## [3.0.6] - 2025-02-04

### Added

- **Get User** – New operation under User resource to retrieve a single user by identifier (External ID, User ID, User Name, or Identity Number). Aligns with Blossom Sync API V2 `GetUser` endpoint.

### Improved

- **Documentation**
  - README: Added operations summary table, Get User section and example, corrected sync workflow (CSV operations are supported), and clarified Features list.
  - COMPLETE_FEATURES_LIST: Added Get User, fixed numbering, updated version and date.
  - Blossom.node.json: Added description for primary documentation link.
- **Community node** – Recommendations and alignment with Postman collection (see repo root `POSTMAN_EZTEST_RECOMMENDATIONS.md` for sync with Postman/EzTest).
